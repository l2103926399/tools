# 四个小工具

静态站点，纯前端、无后端、无追踪。

在线地址：https://l2103926399.github.io/tools/

| 路径 | 工具 |
|---|---|
| `/group/` | 小组成员贡献度 |
| `/profit/` | 经营测算小工具 |
| `/survey/` | 问卷数据分析 |
| `/business/` | 商业分析模型工具箱 |

数据都存在浏览器本地（localStorage / IndexedDB），换设备请用各工具的「导出备份 / 导入备份」迁移。

> 小组成员贡献度目前是「导出 JSON → 组员导入」的手动同步，不是实时共享。
